## Mathematical Logic, Automated Reasoning, and Type Systems

Welcome to the repository for the Mathematical Logic, Automated Reasoning, and Type Systems course. This repository contains the course schedule, lecture notes, curriculums, and Python implementations used throughout the semester.

## Repository Structure

The repository is organized into the following directories:

- curriculums: Detailed course outlines, topics covered week by week, and syllabus information.
- notes: Documentation consisting of interactions with Google Gemini, verifying and exploring whether specific topics or concepts (X) are officially covered within the course curriculum.
- python: Complete Python implementations of automated reasoning algorithms, translated from the original OCaml source code in John Harrison's book.

## Core Topics Covered

1. Mathematical Logic

- Propositional and First-Order Logic
  - Syntax, semantics, soundness, and completeness
  - Proof systems (Natural Deduction, Sequent Calculus)

2. Automated Reasoning

- SAT and SMT solving techniques
  - Resolution and tableaux methods
  - Unification algorithms and automated theorem proving

3. Type Systems

- Simply Typed Lambda Calculus ($\lambda^\to$)
  - The Curry-Howard Isomorphism
  - Dependent types and type checking algorithms

## Additional Courses & Curriculums

Apart from the standard syllabus (main.md), the curriculums folder hosts materials for the following specialized logic and computer science tracks:

- Category Theory I, II, & III (category_theory.md, category_theory2.md, category_theory3.md): Mathematical structures, functors, natural transformations, and limits.
- Answer Set Programming (asp.md): Declarative logic programming oriented towards difficult search problems.
- CDCL (cdcl.md): Conflict-Driven Clause Learning algorithms for modern SAT solvers.
- Computational Complexity (complexity_course.md): Study of resources needed to solve computational problems (P vs NP, space/time complexity).
- Datalog± (datalog+-.md): Extensions of Datalog for ontological reasoning and query answering under constraints.
- Formal Verification (formal_verification.md): Mathematical methods to prove the correctness of hardware and software systems.
- Warren's Abstract Machine (wam.md): Abstract architecture and instruction set for execution of Prolog.
